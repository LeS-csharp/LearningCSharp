# LeS-csharp

Привет! Это мой личный репозиторий, в котором я веду хронику своего пути в IT.

**Цель:** Поступление в один из университетов Европы на IT-специальность через 3+ года.

**Стек:** C#, .NET, WinForms, ASP.NET Core, SQL, Entity Framework.

---

## 🗺️ План на 3 года

| Год | Фокус | Ключевые технологии | Итоговый проект |
| :--- | :--- | :--- | :--- |
| **1** | Основы C#, ООП, WinForms, работа с файлами | C#, LINQ, JSON, WinForms | Консольные и десктоп-приложения (калькулятор, телефонная книга, заметки) |
| **2** | Базы данных, архитектура, веб-API | SQL, Entity Framework, ASP.NET Core, Dependency Injection | REST API для планировщика задач |
| **3** | Полноценный проект, тесты, деплой, портфолио | React/Blazor, Docker, xUnit, ChatGPT API | **EuropePlanner** — умный планировщик с ИИ-помощником |
